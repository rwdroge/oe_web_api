# ABL Unit Test Generator Workflow

This workflow helps you generate comprehensive unit tests for existing ABL code using the OpenEdge ABLUnit framework.

## Prerequisites

Before generating tests, ensure:
1. The target class/procedure exists and is compilable
2. OpenEdge ABLUnit framework is available in the project
3. Test directory structure exists at `src/tests/`

## Important: Use OpenEdge MCP Server

**ALWAYS use the `openedge-abl-mcp-server` MCP server for:**
- ABL syntax verification and best practices
- ABLUnit framework documentation and patterns
- OpenEdge-specific testing approaches
- Correct use of Assert methods and annotations
- Progress.Lang.* class usage

Query the MCP server with collection **12.8** for the most current OpenEdge documentation when you need clarification on:
- ABL syntax (USING statements, DEFINE VARIABLE, METHOD syntax)
- ABLUnit annotations (@Test, @Setup, @TearDown, @Before, @After)
- OpenEdge.Core.Assert methods
- Progress.Json.ObjectModel classes
- Error handling patterns (CATCH blocks, Progress.Lang.Error)

## CRITICAL: OpenEdge.Core.Assert API Reference

**ALWAYS use these exact method signatures from OpenEdge.Core.Assert:**

### Comparison Methods (TWO parameters only - no message parameter)
```abl
Assert:Equals(expected, actual)  /* For character, integer, decimal, date, datetime, etc. */
Assert:NotEqual(expected, actual)
```

### Boolean Assertions (WITH message parameter)
```abl
Assert:IsTrue(condition, "message")
Assert:IsFalse(condition, "message")
```

### Null/Unknown Checks (WITH message parameter)
```abl
Assert:NotNull(object, "message")
Assert:IsNull(object, "message")
Assert:IsUnknown(value, "message")
Assert:NotUnknown(value, "message")
```

### Explicit Test Failure
```abl
Assert:RaiseError("message")  /* NOT Assert:Fail() - that method does not exist! */
```

### Enum Comparisons
For comparing enums like JsonDataType, use IsTrue with comparison:
```abl
Assert:IsTrue(oJson:GetType("field") = JsonDataType:STRING, "Should be string type")
/* NOT: Assert:Equals(JsonDataType:STRING, oJson:GetType("field")) */
```

## Workflow Steps

### 1. Identify Target Code

First, identify the class or procedure to test:
- Ask the user which file needs tests
- Read the target file to understand its structure
- Identify all public methods, properties, and key functionality
- Note any dependencies (USING statements, external classes)

### 2. Analyze Code Structure

For the target code, identify:
- **Class name and namespace**
- **Constructor parameters** (if any)
- **Public methods** with their signatures (parameters, return types)
- **Private methods** that may need indirect testing
- **Properties** (getters/setters)
- **Dependencies** (other classes, database tables, external services)
- **Error handling** patterns
- **Business logic** that needs validation

### 3. Create Test Class Structure

**Before generating code:** Query the `openedge-abl-mcp-server` (collection 12.8) for ABLUnit syntax if needed.

Generate a test class following this pattern:

```abl
/*------------------------------------------------------------------------
    File        : [ClassName]Test
    Purpose     : Unit tests for [ClassName] class
    Syntax      :
    Description : Comprehensive tests for [brief description]
    Author(s)   : Generated by Windsurf AI
    Created     : [Current Date]
    Notes       : Uses OpenEdge ABLUnit framework
  ----------------------------------------------------------------------*/

USING Progress.Lang.*.
USING OpenEdge.Core.Assert.
USING [target.namespace].[ClassName].
USING Progress.Json.ObjectModel.*.

BLOCK-LEVEL ON ERROR UNDO, THROW.

CLASS tests.[namespace].[ClassName]Test:
   
    /* Test fixtures - objects needed for testing */
    DEFINE PRIVATE VARIABLE oTestObject AS [ClassName] NO-UNDO.
   
    /*------------------------------------------------------------------------------
     Purpose: Set up test environment before each test
     Notes:   Runs before EVERY test method
    ------------------------------------------------------------------------------*/
    @Setup.
    METHOD PUBLIC VOID SetUp():
        /* Initialize test object and dependencies */
        oTestObject = NEW [ClassName]([constructor-params]).
    END METHOD.
   
    /*------------------------------------------------------------------------------
     Purpose: Clean up test environment after each test
     Notes:   Runs after EVERY test method
    ------------------------------------------------------------------------------*/
    @TearDown.
    METHOD PUBLIC VOID TearDown():
        /* Clean up resources */
        DELETE OBJECT oTestObject NO-ERROR.
    END METHOD.
   
    /* Test methods go here - one per method being tested */
   
END CLASS.
```

### 4. Generate Test Methods

For **each public method** in the target class, create test methods covering:

#### A. Happy Path Tests
Test normal, expected behavior:

```abl
@Test.
METHOD PUBLIC VOID Test[MethodName]_ValidInput():
    /* Arrange - set up test data */
    DEFINE VARIABLE cInput AS CHARACTER NO-UNDO.
    DEFINE VARIABLE cResult AS CHARACTER NO-UNDO.
   
    ASSIGN cInput = "valid test data".
   
    /* Act - call the method */
    ASSIGN cResult = oTestObject:[MethodName](cInput).
   
    /* Assert - verify results */
    Assert:NotNull(cResult, "Result should not be null").
    Assert:Equals("expected value", cResult, "Result should match expected value").
END METHOD.
```

#### B. Edge Case Tests
Test boundary conditions:

```abl
@Test.
METHOD PUBLIC VOID Test[MethodName]_EmptyInput():
    DEFINE VARIABLE cResult AS CHARACTER NO-UNDO.
   
    /* Test with empty string */
    ASSIGN cResult = oTestObject:[MethodName]("").
   
    Assert:Equals("", cResult, "Should handle empty input gracefully").
END METHOD.

@Test.
METHOD PUBLIC VOID Test[MethodName]_NullInput():
    DEFINE VARIABLE cResult AS CHARACTER NO-UNDO.
   
    /* Test with unknown value */
    ASSIGN cResult = oTestObject:[MethodName](?).
   
    Assert:Equals("", cResult, "Should handle null input gracefully").
END METHOD.
```

#### C. Error Handling Tests
Test exception scenarios:

```abl
@Test(expected="Progress.Lang.AppError").
METHOD PUBLIC VOID Test[MethodName]_ThrowsErrorOnInvalidInput():
    /* This test expects an AppError to be thrown */
    oTestObject:[MethodName]("invalid data that should cause error").
   
    /* If we reach here, test fails (no error was thrown) */
    Assert:Fail("Expected AppError was not thrown").
END METHOD.
```

#### D. Data Validation Tests
For methods that validate data:

```abl
@Test.
METHOD PUBLIC VOID TestValidateBSN_ValidBSN():
    DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
   
    /* Test with known valid BSN */
    ASSIGN lResult = oTestObject:ValidateBSN("111222333").
   
    Assert:IsTrue(lResult, "Valid BSN should pass validation").
END METHOD.

@Test.
METHOD PUBLIC VOID TestValidateBSN_InvalidBSN():
    DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
   
    /* Test with invalid BSN (fails 11-proef) */
    ASSIGN lResult = oTestObject:ValidateBSN("123456789").
   
    Assert:IsFalse(lResult, "Invalid BSN should fail validation").
END METHOD.
```

### 5. Test Private Methods Indirectly

For private methods, test them through public methods that call them:

```abl
@Test.
METHOD PUBLIC VOID TestPublicMethod_CallsPrivateMethodCorrectly():
    /* Test that public method produces expected result */
    /* This indirectly tests the private method it calls */
    DEFINE VARIABLE cResult AS CHARACTER NO-UNDO.
   
    ASSIGN cResult = oTestObject:PublicMethod("input").
   
    /* Verify the result shows private method worked */
    Assert:Contains("expected substring", cResult,
                   "Result should contain output from private method").
END METHOD.
```

### 6. Mock External Dependencies

For classes with external dependencies (database, web services):

```abl
/* Create mock objects in SetUp */
@Setup.
METHOD PUBLIC VOID SetUp():
    DEFINE VARIABLE oMockService AS MockService NO-UNDO.
   
    /* Create mock that simulates external dependency */
    oMockService = NEW MockService().
   
    /* Initialize test object with mock */
    oTestObject = NEW [ClassName](oMockService).
END METHOD.
```

### 7. Test Database Operations

For methods that access database tables:

```abl
@Test.
METHOD PUBLIC VOID TestFindClient_ExistingClient():
    /* Arrange - create test data in database */
    CREATE bcaclt.
    ASSIGN bcaclt.rclnt = 12345
           bcaclt.nname = "Test Client"
           bcaclt.rsofi = "123456789".
   
    /* Act - call method that queries database */
    DEFINE VARIABLE oResult AS JsonObject NO-UNDO.
    ASSIGN oResult = oTestObject:FindClient(12345).
   
    /* Assert - verify results */
    Assert:NotNull(oResult, "Should find existing client").
    Assert:Equals("Test Client", oResult:GetCharacter("name"),
                 "Should return correct client name").
   
    /* Cleanup - delete test data */
    DELETE bcaclt.
END METHOD.
```

### 8. Add Test to Test Suite

Update `src/tests/ablunit.json` to include the new test:

```json
{
  "tests": [
    {
      "test": "tests.[namespace].[ClassName]Test"
    }
  ]
}
```

### 9. Run Tests

Execute tests using:

```bash
# Run all tests
_progres -b -p src/tests/RunAllTests.p

# Or run specific test class
_progres -b -p src/tests/RunNewTests.p -param "tests.[namespace].[ClassName]Test"
```

## Best Practices

### Naming Conventions
- Test class: `[ClassName]Test.cls`
- Test methods: `Test[MethodName]_[Scenario]()`
- Use descriptive scenario names: `_ValidInput`, `_EmptyString`, `_ThrowsError`

### Test Structure (AAA Pattern)
```abl
/* Arrange - set up test data and conditions */
DEFINE VARIABLE cInput AS CHARACTER NO-UNDO.
ASSIGN cInput = "test data".

/* Act - execute the method being tested */
DEFINE VARIABLE cResult AS CHARACTER NO-UNDO.
ASSIGN cResult = oTestObject:MethodUnderTest(cInput).

/* Assert - verify the results */
Assert:Equals("expected", cResult, "Descriptive failure message").
```

### Assertion Methods
- `Assert:IsTrue(condition, message)` - Verify boolean is true
- `Assert:IsFalse(condition, message)` - Verify boolean is false
- `Assert:Equals(expected, actual, message)` - Verify equality
- `Assert:NotEquals(expected, actual, message)` - Verify inequality
- `Assert:IsNull(object, message)` - Verify object is null
- `Assert:NotNull(object, message)` - Verify object is not null
- `Assert:Contains(substring, string, message)` - Verify substring exists
- `Assert:Fail(message)` - Force test failure

### Code Coverage Goals
- **Minimum**: 70% code coverage
- **Target**: 80-90% code coverage
- **Focus on**: Business logic, validation, error handling
- **Less critical**: Getters/setters, simple assignments

### Test Independence
- Each test should be independent (no shared state)
- Use `@Setup` and `@TearDown` to ensure clean state
- Don't rely on test execution order
- Clean up test data after each test

### Error Testing
```abl
/* Test that error is thrown */
@Test(expected="Progress.Lang.AppError").
METHOD PUBLIC VOID TestMethod_ThrowsError():
    oTestObject:MethodThatShouldThrow().
END METHOD.

/* Test error message content */
@Test.
METHOD PUBLIC VOID TestMethod_ErrorMessage():
    DEFINE VARIABLE oError AS Progress.Lang.Error NO-UNDO.
   
    CATCH oError AS Progress.Lang.Error:
        Assert:Contains("expected error text", oError:GetMessage(1),
                       "Error message should contain expected text").
    END CATCH.
END METHOD.
```

## Example: Complete Test Class

Here's a complete example for testing a BSN validation method:

```abl
CLASS tests.businessEntities.ClientMatchBETest:
   
    DEFINE PRIVATE VARIABLE oClientMatch AS businessEntities.ClientMatchBE NO-UNDO.
   
    @Setup.
    METHOD PUBLIC VOID SetUp():
        oClientMatch = NEW businessEntities.ClientMatchBE().
    END METHOD.
   
    @TearDown.
    METHOD PUBLIC VOID TearDown():
        DELETE OBJECT oClientMatch NO-ERROR.
    END METHOD.
   
    /* Test valid 9-digit BSN */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_Valid9Digit():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        /* Known valid BSN: 111222333 */
        ASSIGN lResult = oClientMatch:ValidateBSN("111222333").
       
        Assert:IsTrue(lResult, "Valid 9-digit BSN should pass validation").
    END METHOD.
   
    /* Test valid 8-digit BSN */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_Valid8Digit():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        /* Valid 8-digit BSN */
        ASSIGN lResult = oClientMatch:ValidateBSN("12345678").
       
        Assert:IsTrue(lResult, "Valid 8-digit BSN should pass validation").
    END METHOD.
   
    /* Test invalid BSN (fails 11-proef) */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_Invalid11Proef():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        /* Invalid BSN - doesn't pass modulo 11 check */
        ASSIGN lResult = oClientMatch:ValidateBSN("123456789").
       
        Assert:IsFalse(lResult, "Invalid BSN should fail validation").
    END METHOD.
   
    /* Test empty input */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_EmptyString():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        ASSIGN lResult = oClientMatch:ValidateBSN("").
       
        Assert:IsFalse(lResult, "Empty string should fail validation").
    END METHOD.
   
    /* Test null input */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_NullValue():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        ASSIGN lResult = oClientMatch:ValidateBSN(?).
       
        Assert:IsFalse(lResult, "Null value should fail validation").
    END METHOD.
   
    /* Test non-numeric input */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_NonNumeric():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        ASSIGN lResult = oClientMatch:ValidateBSN("ABC123DEF").
       
        Assert:IsFalse(lResult, "Non-numeric input should fail validation").
    END METHOD.
   
    /* Test too short */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_TooShort():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        ASSIGN lResult = oClientMatch:ValidateBSN("1234567").
       
        Assert:IsFalse(lResult, "7-digit number should fail validation").
    END METHOD.
   
    /* Test too long */
    @Test.
    METHOD PUBLIC VOID TestValidateBSN_TooLong():
        DEFINE VARIABLE lResult AS LOGICAL NO-UNDO.
       
        ASSIGN lResult = oClientMatch:ValidateBSN("1234567890").
       
        Assert:IsFalse(lResult, "10-digit number should fail validation").
    END METHOD.
   
END CLASS.
```

## Checklist

Before completing test generation:

- [ ] Test class created in correct directory (`src/tests/[namespace]/`)
- [ ] All public methods have at least one test
- [ ] Happy path scenarios covered
- [ ] Edge cases tested (empty, null, boundary values)
- [ ] Error handling tested
- [ ] Test added to `ablunit.json`
- [ ] Tests compile without errors
- [ ] Tests run and pass
- [ ] Code coverage meets minimum threshold (70%)
- [ ] Test names are descriptive and follow conventions
- [ ] Each test has clear Arrange-Act-Assert structure
- [ ] Assertions have descriptive failure messages

## Common Issues

### Issue: "Class not found" error
**Solution**: Ensure PROPATH includes both `src/` and `src/tests/` directories

### Issue: Tests fail with database errors
**Solution**: Ensure test database is connected before running tests

### Issue: Mock objects not working
**Solution**: Create mock classes in `src/tests/mocks/` directory

### Issue: Tests pass individually but fail when run together
**Solution**: Check for shared state, ensure proper cleanup in `@TearDown`
