# Examples Directory

## HashMap Collection Examples - Moved! 🎯

The HashMap collection examples have been moved to a dedicated repository for the **PUG Challenge 2025**:

**📦 Repository:** https://github.com/rwdroge/pug25_abl_examples

### What's in the new repository?

- **HashMapExamples.cls** - 8 different HashMap example patterns
- **RequestHeaderParser.cls** - Real-world HTTP header parser utility
- **run_hashmap_examples.p** - Demo program for all examples
- **demo_header_parser.p** - Interactive header parser demo
- **Comprehensive documentation** - Usage guides, API reference, and best practices

### Why the move?

The HashMap examples are standalone educational content suitable for the PUG Challenge 2025 and can benefit the broader ABL community independently of this API project.

### Quick Start

```bash
# Clone the examples repository
git clone https://github.com/rwdroge/pug25_abl_examples.git

# Run the examples
cd pug25_abl_examples
RUN run_hashmap_examples.p
RUN demo_header_parser.p
```
